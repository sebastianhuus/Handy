# Pure-Python reference-implementation harness for candidate long-form ASR
# engines (NVIDIA Parakeet-TDT, NVIDIA Canary), deliberately decoupled from
# chunk_harness/ (Rust, transcribe-rs/ONNX -- what the app would actually
# ship) until a decision is made on whether/what to change there.
#
# Uses NeMo -- the engines' own reference toolkit -- rather than
# transcribe-rs's ONNX port, specifically because NeMo has documented
# support for real segment/word timestamps on *both* engines (Parakeet's
# ONNX port already exposes these; Canary's currently does not -- see
# ../SPEC.md and README.md in this directory). Heavy dependency (torch +
# nemo pull several GB) -- that's an accepted tradeoff for using the
# correctness-reference implementation rather than reimplementing TDT/AED
# decoding by hand.
